# Discovery Web Piscine

## Project Overview

This project is part of the Discovery Web Piscine. The purpose of this exercise is to practice professional documentation, Git version control, and secure authentication with GitHub.

## Why Git Makes Development Easier

Git makes development easier because it allows developers to track changes to their files and keep a history of the project.

Git allows developers to create commits that record specific changes. This makes it easier to understand what was changed and when it was changed.

Git also provides safeguards because developers can return to previous versions of their work if a mistake is made. This helps prevent the loss of important work.

Another important advantage of Git is collaboration. Multiple developers can work on the same project, share their changes, and collaborate through platforms such as GitHub.

Overall, Git makes development easier by providing version control, change tracking, project history, safeguards, and collaboration.

## Git Commands

### git init

Initializes a new Git repository in the current directory.

### git status

Shows the current state of the Git repository and displays information about modified, staged, and untracked files.

### git add

Adds files or changes to the staging area before they are committed.

### git commit

Saves the staged changes in the Git history with a commit message.

### git log

Displays the history of commits in the repository.

### git remote

Manages connections between the local repository and remote repositories such as GitHub.

### git push

Uploads local commits to the remote GitHub repository.

## SSH Authentication

SSH provides a secure way to authenticate with GitHub without entering a password every time.

An SSH key pair contains a private key and a public key. The public key can be added to GitHub to identify the computer.

The private key must remain secret and must never be submitted or committed to the repository.

## Git Workflow

The basic Git workflow is:

1. Edit files.
2. Check the repository with `git status`.
3. Stage changes with `git add`.
4. Commit changes with `git commit`.
5. Push commits to GitHub with `git push`.

## Conclusion

Git provides an organized way to manage projects, track changes, protect work, and collaborate with other developers. GitHub provides remote repository hosting and collaboration, while SSH provides secure authentication.
